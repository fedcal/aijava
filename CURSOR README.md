# Cursor readme 


Spiegazione delle Migliorie:

- Titolo e Introduzione: Aggiunto un titolo chiaro e un'introduzione che spiega lo scopo del file ("PROJECT CONTEXT AND GUIDELINES FOR AI ASSISTANCE" e "Questa sezione fornisce contesto generale...").
- Commenti Descrittivi: Ogni sezione ora include un commento (#) che ne descrive lo scopo in modo esplicito, spiegando perché è utile per l'AI.
- Processo di Correzione Errori Dettagliato: I passi per la correzione degli errori sono stati resi più specifici, guidando l'AI attraverso un processo logico di analisi, identificazione, suggerimento e verifica.
- Processo di Build Espanso: La sezione "BUILDING PROCESS" ora include suggerimenti per dettagliare i comandi e i prerequisiti necessari per costruire il progetto.
- Struttura File con Istruzioni: La sezione "CURRENT FILE STRUCTURE" spiega che lo scopo è fornire una mappa del progetto all'AI e include l'istruzione su come generare l'output del comando tree.
- Processo GitHub Dettagliato: La sezione "GITHUB PUSH PROCESS" elenca i comandi Git standard, rendendo più facile per l'AI assistere con le operazioni di version control.
- Sezione IMPORTANT Chiarita: Viene spiegato cosa dovrebbe essere incluso nella sezione "IMPORTANT" (direttive cruciali, avvertenze) e vengono forniti esempi.
- Sezione OTHER CONTEXT Ampliata: Viene chiarito che questa sezione è un "catch-all" per informazioni aggiuntive e vengono forniti esempi del tipo di contenuto da includere.
- Separatori Visivi: L'uso di --- aiuta a separare visivamente le sezioni, migliorando la leggibilità.

Questa struttura rende il file un "manifesto" per il progetto che l'AI può consultare per capire come operare al meglio all'interno del tuo specifico contesto di sviluppo. Ricorda di riempire le sezioni con le informazioni specifiche del tuo progetto.
